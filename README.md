<a name="통합-위치"></a>

## 🧭 통합 위치

한국컴퓨터교육학회 **제58회 2026 하계학술대회**의 「EfficientNetV2-S 모델에서 개인정보 보호를 위한 영상 비식별화 기법의 성능 분석」을 폐암 CT 프라이버시 연구의 **연구 1**로 통합했습니다. 이어지는 ResNet50 연구와 후속 특징맵 실험을 하나의 연구 흐름으로 읽을 수 있습니다.

<a name="이-저장소의-역할"></a>

## 🧭 이 저장소의 역할

이곳은 하계 연구의 이전 커밋을 찾아보고 통합 저장소로 이동하는 안내 페이지입니다. 현재 논문과 그래프 코드는 위 링크에서 확인할 수 있고, 이전 커밋 이력은 이 저장소에 남아 있습니다.

[공개 사본 변환 기록](docs/SANITIZATION.md)은 이동 이전의 처리 범위를 보존하며, [버전 기록](docs/VERSIONS.md)은 이관 후 현재 파일 구성과 이동 위치를 설명합니다. 새 코드와 논문은 위 통합 저장소를 기준으로 확인해 주세요.
