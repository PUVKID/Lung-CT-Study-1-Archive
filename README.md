## 이 저장소의 역할

최신 트리에서는 통합 위치로 옮긴 논문·그래프의 중복 사본을 제거하고 이전 변경 이력과 이동 안내를 보존합니다. 원본의 이전 연구 차수나 커밋 이력을 삭제하는 작업은 아닙니다. 이전 자료의 커밋 이력과 이동 안내를 보존하는 용도로 사용합니다.

[공개 사본 변환 기록](docs/SANITIZATION.md)은 이동 이전의 처리 범위를 보존하며, [버전 기록](docs/VERSIONS.md)은 이관 후 현재 파일 구성과 이동 위치를 설명합니다. 새 코드와 논문은 위 통합 저장소를 기준으로 확인해 주세요.
